Supervised dan Unsupervised Learning

Data Mining (MI0439)

Penulis

Dr. Indira Puteri Kinasih

Capaian Pembelajaran

Setelah mengikuti pertemuan ini, mahasiswa mampu:

  • menjelaskan konsep supervised learning dan unsupervised learning;
  • membedakan supervised dan unsupervised learning berdasarkan tujuan dan karakteristik datanya;
  • mengidentifikasi contoh penerapan kedua pendekatan dalam konteks pendidikan;
  • menentukan pendekatan yang sesuai untuk suatu permasalahan sederhana dalam Educational Data Mining (EDM).

Mengapa Machine Learning?

Pada pertemuan sebelumnya, kita telah melakukan Analisis Eksplorasi Data (EDA) untuk memahami pola dalam data.

EDA membantu kita menjawab:

“Apa yang terlihat dalam data?”

Machine learning melangkah lebih jauh:

“Apakah pola dalam data dapat digunakan untuk membuat prediksi atau menemukan kelompok/pola tertentu?”

Dalam EDM, machine learning dapat digunakan untuk membantu memahami perilaku belajar, memprediksi hasil belajar, menemukan kelompok siswa, dan mengidentifikasi pola aktivitas pembelajaran.

Machine Learning

Machine learning adalah pendekatan yang memungkinkan komputer mempelajari pola dari data untuk menghasilkan prediksi, klasifikasi, atau menemukan struktur tertentu dalam data.

Secara sederhana:

Data → Proses Pembelajaran → Model → Prediksi / Pola

Contoh dalam pendidikan:

  • memprediksi apakah siswa berisiko mengalami kesulitan belajar;
  • memprediksi nilai akhir siswa;
  • mengelompokkan siswa berdasarkan pola aktivitas belajar;
  • menemukan kelompok siswa dengan karakteristik pembelajaran yang serupa.

Dua Pendekatan Utama

Dalam konteks dasar machine learning, terdapat dua pendekatan yang perlu dibedakan:

Pendekatan Tujuan utama Data memiliki target? Contoh EDM
Supervised learning Mempelajari hubungan untuk melakukan prediksi atau klasifikasi ✓ Memprediksi kelulusan siswa
Unsupervised learning Menemukan pola atau struktur dalam data ✗ Mengelompokkan siswa berdasarkan aktivitas belajar

Perbedaan utama terletak pada ada atau tidaknya target yang ingin diprediksi.

Supervised Learning

Pada supervised learning, model belajar menggunakan data yang sudah memiliki target atau label.

Struktur sederhananya:

Input (X) → Target (Y)

Model mempelajari hubungan antara variabel input dan target.

Contoh:

Kehadiran Waktu Belajar Aktivitas LMS Nilai UAS
95 5 12 82
90 7 15 88
75 3 8 68
… … … …

Jika tujuan kita adalah memprediksi Nilai UAS, maka:

  • X = Kehadiran, Waktu Belajar, Aktivitas LMS
  • Y = Nilai UAS

Model belajar dari data tersebut untuk memprediksi nilai UAS pada data baru.

Supervised Learning dalam EDM

Beberapa pertanyaan pendidikan yang dapat menggunakan supervised learning:

Pertanyaan Target Jenis masalah
Berapa perkiraan nilai akhir siswa? Nilai akhir Regresi
Apakah siswa akan lulus? Lulus / Tidak lulus Klasifikasi
Apakah siswa berisiko mengalami kesulitan belajar? Risiko / Tidak Klasifikasi
Berapa nilai matematika yang mungkin diperoleh siswa? Nilai Regresi

Dua bentuk yang penting

Regresi

Target berupa nilai numerik.

Y = f(X) + \varepsilon

Contoh: memprediksi nilai UAS.

Klasifikasi

Target berupa kategori.

Contoh:

Siswa → Lulus atau Tidak Lulus

Contoh: Prediksi Hasil Belajar

Misalkan tersedia data:

Kehadiran Waktu Belajar Aktivitas LMS Nilai UAS
95 5 12 82
90 7 15 88
75 3 8 68
85 4 10 76
… … … …

Pertanyaan:

Dapatkah kita memprediksi nilai UAS berdasarkan aktivitas belajar siswa?

Karena Nilai UAS sudah diketahui dalam data pelatihan, masalah ini termasuk:

Supervised Learning → Regresi

Unsupervised Learning

Pada unsupervised learning, data tidak memiliki target yang ingin diprediksi.

Model digunakan untuk menemukan struktur, kelompok, atau pola dalam data.

Struktur sederhananya:

Input (X) → Pola / Struktur

Contoh:

Siswa Kehadiran Waktu Belajar Aktivitas LMS
S01 95 5 12
S02 92 6 15
S03 70 2 5
S04 73 3 6
… … … …

Kita tidak menentukan terlebih dahulu apakah siswa termasuk kelompok tertentu.

Model dapat digunakan untuk menemukan kelompok siswa berdasarkan kemiripan karakteristiknya.

Unsupervised Learning dalam EDM

Salah satu contoh paling sederhana adalah clustering.

Misalnya, berdasarkan aktivitas belajar, model menemukan tiga kelompok:

Kelompok Karakteristik
Kelompok A Aktivitas belajar tinggi
Kelompok B Aktivitas belajar sedang
Kelompok C Aktivitas belajar rendah

Kelompok tersebut tidak ditentukan sebelumnya oleh peneliti.

Model menemukan kelompok berdasarkan pola yang terdapat dalam data.

Contoh: Mengelompokkan Siswa

Pertanyaan:

Apakah terdapat kelompok siswa dengan pola aktivitas belajar yang berbeda?

Variabel yang digunakan:

  • Kehadiran
  • Waktu belajar
  • Aktivitas LMS
  • Jumlah latihan

Tidak ada variabel target yang ingin diprediksi.

Maka pendekatannya:

Unsupervised Learning → Clustering

Supervised vs Unsupervised

Karakteristik Supervised Unsupervised
Target/label Ada Tidak ada
Tujuan Prediksi / klasifikasi Menemukan pola / kelompok
Pertanyaan utama “Apa yang akan terjadi?” “Pola apa yang terdapat dalam data?”
Contoh Prediksi nilai Pengelompokan siswa
Contoh metode Regresi, klasifikasi Clustering

Cara sederhana membedakannya

Ada target yang ingin diprediksi? → Supervised

Tidak ada target dan ingin mencari pola? → Unsupervised

Contoh Kasus Pendidikan

Perhatikan beberapa kasus berikut.

Kasus Pendekatan
Memprediksi nilai UAS berdasarkan nilai tugas dan kehadiran Supervised
Memprediksi apakah siswa akan lulus Supervised
Mengelompokkan siswa berdasarkan pola belajar Unsupervised
Mencari kelompok siswa dengan pola penggunaan LMS yang serupa Unsupervised
Memprediksi siswa yang berisiko tidak menyelesaikan pembelajaran Supervised

Bagaimana Menentukannya?

Ketika menghadapi suatu permasalahan data, tanyakan:

Apa tujuan analisisnya?

↓

Apakah terdapat target/label yang ingin diprediksi?

↓

Ya → Supervised Learning

Tidak → Unsupervised Learning

Kemudian tentukan metode yang sesuai dengan jenis permasalahannya.

Studi Kasus

Sebuah madrasah memiliki data:

  • kehadiran siswa;
  • nilai tugas;
  • nilai kuis;
  • aktivitas LMS;
  • waktu belajar;
  • nilai akhir.

Perhatikan beberapa tujuan berikut.

Kasus A

Guru ingin memprediksi nilai akhir siswa berdasarkan aktivitas belajarnya.

Kasus B

Guru ingin mengetahui apakah terdapat kelompok siswa dengan pola aktivitas belajar yang berbeda.

Diskusikan

  1. Apakah terdapat target pada masing-masing kasus?
  2. Pendekatan apa yang sesuai?
  3. Mengapa?

Machine Learning dalam EDM

Machine learning merupakan salah satu pendekatan yang dapat digunakan dalam Educational Data Mining.

Contohnya:

Data Pendidikan
      ↓
Preprocessing
      ↓
EDA
      ↓
Machine Learning
      ↓
┌───────────────────┐
│ Supervised        │
│ → Prediksi        │
│ → Klasifikasi     │
└───────────────────┘

atau

┌───────────────────┐
│ Unsupervised      │
│ → Clustering      │
│ → Menemukan pola  │
└───────────────────┘

Namun, penggunaan machine learning tidak dimulai dari pemilihan algoritma.

Kita terlebih dahulu perlu memahami:

data → pertanyaan → tujuan analisis → metode
